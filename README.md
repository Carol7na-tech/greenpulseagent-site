## Português

Página de portfólio do **Green Pulse Agent**, um copiloto de IA para pré-análise financeira e climática de projetos de energia solar. Construí o projeto sozinha em 45 dias para o hackathon Build with Gemini, promovido pelo XPRIZE. Hoje ele está arquivado e o backend não está mais ativo.

Esta página é estática e existe só como registro do projeto. Ela reúne:

- a explicação de como o sistema funciona, da entrada dos dados à entrega do relatório;
- capturas da interface original;
- uma calculadora que roda no navegador, com as mesmas fórmulas do motor original (VPL, TIR e payback);
- um relatório de exemplo em PDF (todos os dados são fictícios);
- o vídeo de demonstração e os links do projeto.

Não há coleta de dados, backend ativo nem processamento de pagamentos.

## English

Portfolio page for **Green Pulse Agent**, an AI copilot for financial and climate pre-screening of solar energy projects. I built the project solo in 45 days for the Build with Gemini hackathon, hosted by XPRIZE. It is archived today and the backend is no longer active.

This is a static page that exists only as a record of the project. It includes:

- an explanation of how the system works, from data input to report delivery;
- screenshots of the original interface;
- a calculator that runs in the browser, using the same formulas as the original engine (NPV, IRR and payback);
- a sample report in PDF (all data is fictional);
- the demo video and project links.

There is no data collection, active backend or payment processing.

| File | Purpose |
